# 智读小站 · 部署安装说明

> **这份文档是给 AI 助手看的。** 把整个文件内容丢进 AI 对话里，让它照着执行即可。
> 文档里带 *斜体* 的地方是给人看的备注，AI 可以跳过。

---

## 0. 给 AI 的六条原则（务必先读）

你正在帮用户在一台 Windows 电脑上部署一个叫「智读小站」的 Python 项目
（AI 文献阅读助手：上传 PDF/Word/Markdown/文本 → 生成摘要 → 带出处的问答 → 学术翻译）。

请遵守：

1. **先体检，再动手。** 必须先执行第 2 步的体检脚本，根据结果决定装什么。
2. **能复用就复用。** 本机已有的 Python、已装的包、已下载的模型，一律复用，不要重复下载。
3. **联网优先走国内镜像。** pip 用阿里云，模型用 hf-mirror.com。这台机器在国内。
4. **每一步都要验证。** 装完立刻验证，不要假设成功；失败时看完整报错再决定下一步。
5. **不要拿技术细节去问用户。** 用户会把报错原文贴给你，你自己判断怎么修。
6. **环境**：Windows，PowerShell 或 CMD 都行。路径含中文或空格时记得加引号。

---

## 1. 最终要达成的目标

在这台电脑上跑起来一个本地网页服务，浏览器打开 `http://127.0.0.1:5000` 后可以：

- 注册账号并登录
- 上传 PDF / .docx / .md / .txt，自动建立语义索引（**有显卡的话几秒钟**）
- 生成结构化摘要，每条结论带 `p.3` 这样的出处按钮，点一下跳到原文对应位置
- 基于文献内容提问，答案同样带出处
- 学术翻译

## 3. 第二步：按体检结果决定装什么

| 体检结果 | 怎么做 |
|---|---|
| Python 是 32 位 | **停下来**，让用户去 python.org 装 64 位 Python 3.12 或 3.13 |
| Python < 3.9 | 同上，装 3.12 或 3.13 |
| `torch` 那行显示 **[有] 且 CUDA 可用: True** | **完全跳过第 4 步**，不要动它，直接用 |
| `torch` 那行显示 **[有] 但是 CPU 版**（`是否 CUDA 编译: False`） | 执行第 4 步**替换**成 CUDA 版 |
| `torch` 那行显示 **[无]** | 执行第 4 步安装 |
| 其他包缺哪个 | 第 5 步一起装 |
| `Qwen3-Embedding-0.6B 已缓存: True` | 可以直接用，但仍建议照第 6 步用 `EMBEDDING_MODEL_PATH` 显式指定路径，最省心 |
| `Qwen3-Embedding-0.6B 已缓存: False` | **必须**照第 6 步下载模型（约 1.15 GB，40 秒） |

> *本机已验证可用的版本组合（供参考，不必强求一致）：
> Python 3.13.7 64 位 + torch 2.11.0+cu128 + transformers 5.7.0 +
> sentence-transformers 5.4.1 + faiss-cpu 1.13.2 + PyMuPDF 1.27.2.3*

## 4. 第三步：安装 CUDA 版 torch（约 2.6 GB）

**直接联网装就行**，pip 会自动挑与本机 Python 版本匹配的轮子（3.9~3.14 全都支持）。

### 4.1 如果之前装过 CPU 版 torch，先卸载

同一个环境里不能同时存在两个 torch：

```powershell
python -m pip uninstall -y torch
```

> 怎么判断是不是 CPU 版：体检输出里 `是否 CUDA 编译: False` 就是 CPU 版。

### 4.2 安装

```powershell
python -m pip install torch --index-url https://download.pytorch.org/whl/cu128
```

- 约 **2.6 GB**。这个源在国内速度很不稳定（实测有的机器只有 0.5 MB/s，要下十几分钟）
- **断了就重跑同一条命令**，pip 支持断点续传，不会从头开始
- 想快一点可以试试 `cu130` 源（包更小，约 1.85 GB，但需要显卡驱动 ≥ 580）：
  `python -m pip install torch --index-url https://download.pytorch.org/whl/cu130`
- **如果下载实在太慢**：告诉用户可以用国内镜像站手动下这个文件再本地安装，
  文件名规则是 `torch-<版本>+cu128-cp<Python版本>-cp<Python版本>-win_amd64.whl`，
  比如 Python 3.14 就是 `torch-2.11.0+cu128-cp314-cp314-win_amd64.whl`

### 4.3 装完立刻验证（这一步必须做）

```powershell
python -c "import torch;print(torch.__version__);print('CUDA可用:',torch.cuda.is_available());print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else '')"
```

**期望输出**：版本号带 `+cu128`、`CUDA可用: True`、显卡型号。

如果 `CUDA可用: False`：
- 先看 `python -c "import torch;print(torch.version.cuda)"`。是 `None` 说明装成了 CPU 版，回到 4.2 重装；
- 有值但仍 False，多半是**显卡驱动太旧**，让用户去 NVIDIA 官网更新驱动后重启。

## 6. 第五步：准备向量模型（1.15 GB）

**先说清楚为什么不能省这一步**：程序默认**不会联网下载模型**（刻意设计，避免偷偷下东西）。
而且实测过"设个 HuggingFace 国内镜像让它自己下"这条路——**是失败的**，
`huggingface_hub` 校验不过镜像返回的元数据，会报 `FileMetadataError`。

**所以必须用下面这个方法手动下**。它已经完整实测通过：
9 个文件、1.12 GB、**40 秒下完**（24 MB/s），下完在断网状态下能正常加载出 1024 维向量。

### 6.1 下载（从阿里 ModelScope 魔搭，不走 HuggingFace）

把下面这段存成 `download_model.py`，然后 `python download_model.py D:\model`：

```python
# -*- coding: utf-8 -*-
"""从 ModelScope（阿里魔搭）下载 Qwen3-Embedding-0.6B。不需要任何第三方库。"""
import sys, time, urllib.parse, urllib.request
from pathlib import Path

MODEL_ID = "Qwen/Qwen3-Embedding-0.6B"
BASE = f"https://www.modelscope.cn/api/v1/models/{MODEL_ID}/repo?Revision=master&FilePath="
FILES = ["config.json", "config_sentence_transformers.json", "modules.json",
         "model.safetensors", "tokenizer.json", "tokenizer_config.json",
         "vocab.json", "merges.txt", "1_Pooling/config.json"]


def human(num):
    return f"{num / 1024 ** 3:.2f} GB" if num >= 1024 ** 3 else f"{num / 1024 ** 2:.1f} MB"


def download(url, dest):
    request = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    with urllib.request.urlopen(request, timeout=180) as response, open(dest, "wb") as handle:
        total = int(response.headers.get("Content-Length") or 0)
        got, last, started = 0, 0.0, time.time()
        while True:
            chunk = response.read(1024 * 512)
            if not chunk:
                break
            handle.write(chunk)
            got += len(chunk)
            now = time.time()
            if total and now - last > 1.5:
                last = now
                sys.stdout.write(f"\r    {got * 100.0 / total:5.1f}%  {human(got)}/{human(total)}  ")
                sys.stdout.flush()
        if total:
            sys.stdout.write("\r" + " " * 50 + "\r")
    return got


def main():
    target = Path(sys.argv[1]) if len(sys.argv) > 1 else Path("model")
    target.mkdir(parents=True, exist_ok=True)
    print(f"下载 {MODEL_ID} -> {target.resolve()}\n")
    failed = []
    for index, name in enumerate(FILES, 1):
        dest = target / name
        dest.parent.mkdir(parents=True, exist_ok=True)
        if dest.exists() and dest.stat().st_size > 0:
            print(f"[{index}/{len(FILES)}] {name}  已存在，跳过")
            continue
        print(f"[{index}/{len(FILES)}] {name}")
        try:
            print(f"    OK {human(download(BASE + urllib.parse.quote(name), dest))}")
        except Exception as exc:
            print(f"    FAIL {type(exc).__name__}: {str(exc)[:90]}")
            failed.append(name)
    total = sum(f.stat().st_size for f in target.rglob("*") if f.is_file())
    print(f"\n完成：{len(FILES) - len(failed)}/{len(FILES)} 个文件，共 {human(total)}")
    if failed:
        print(f"失败：{failed}\n重跑本脚本即可（已下好的会自动跳过）")
        return 1
    print(f"\n下一步：在 backend\\.env 里加一行\nEMBEDDING_MODEL_PATH={target.resolve()}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

> 项目里也带了这个脚本：`tools\download_model.py`，可以直接用，不用手动复制。

**执行：**

```powershell
cd "项目目录"
python tools\download_model.py D:\model
```

### 6.2 告诉程序模型在哪

在 `backend\.env` 里加一行（路径换成上一步实际下载的目录）：

```
EMBEDDING_MODEL_PATH=D:\model
```

**这样就行了**——不需要 HuggingFace 缓存结构，不需要联网，程序会直接从这个目录加载。

### 怎么确认模型已经就位

`EMBEDDING_MODEL_PATH` 指向的目录里应该有这 9 个文件：

```

config_sentence_transformers.json
modules.json
model.safetensors          ← 1.14 GB，真正占地方的就是它
tokenizer.json
tokenizer_config.json
```

缺任何一个都会加载失败。**重跑下载脚本**即可补齐（已下好的会跳过）。

> **如果下载脚本报错**：先用浏览器打开
> `https://www.modelscope.cn/models/Qwen/Qwen3-Embedding-0.6B/files`
> 看看能不能访问；能访问就把报错原文发给 AI 分析。这条下载路子本机实测可用，
> 失败基本是网络临时问题，重试即可。

## 9. 故障排查

| 现象 | 原因与处理 |
|---|---|
| `Torch not compiled with CUDA enabled` | 装成了 CPU 版 torch。卸载后按第 4 步装 CUDA 版 |
| `CUDA可用: False` 但 `torch.version.cuda` 有值 | 显卡驱动太旧（需 ≥ 525），去 NVIDIA 官网更新后重启 |
| 健康检查里 `device` 是 `cpu` | 没检测到显卡。要么驱动问题，要么用的是 CPU 版 torch |
| 界面顶部显示「模型未加载」 | 本机没有模型，或 `EMBEDDING_MODEL_PATH` 指错了。照第 6 步做法 1 做一次 |
| 报 `FileMetadataError` / `couldn't connect to hf-mirror.com` | 这就是"让程序自己下模型"失败的表现（已知问题）。照第 6 步用脚本从 ModelScope 下 |
| 报 `ModuleNotFoundError: docx` | `backend\requirements.txt` 里已经包含它了；如果还报，手动 `python -m pip install python-docx` |
| 界面提示「大模型不可用」 | `.env` 里的 Key 没写对，或 Key 余额不足 |
| 上传 PDF 提示「提取不到有效文字」 | 这是扫描件（图片型），需要 OCR，本项目暂不支持 |
| 端口 5000 被占用 | `netstat -ano | findstr :5000` 找到进程结束掉，或改 `backend\app.py` 最后一行的端口 |
| 上传后一直「建立索引」很慢 | 在用 CPU 跑模型。检查 torch 是否 CUDA 版、驱动是否正常 |
| 网页白屏 | 前端资源在 `vendor\` 目录，确认整个项目文件夹完整拷贝了 |
